Module Boundary is the pattern where a slice renders as a first-class node inside the host's own framework render tree, loaded through the host's native lazy/Suspense/error-boundary machinery — host and slice must share a framework. It has two export styles, [Direct and Injected](/glossary/#slice-conventions), plus a guide for retrofitting it onto an app you already have.

Pick the path that matches what you're building:
